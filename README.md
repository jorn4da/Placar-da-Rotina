# Placar da Rotina — Aritan Especialista

Aplicação web de check-in diário, quiz cronometrado e placar da equipe de corretores.

## O que é
Página única (HTML) usada pela equipe RV Cury Vendas para:
- Registrar o check-in da rotina da manhã (9 tarefas).
- Fazer o Desafio do dia: quiz de 5 perguntas, 25s por pergunta, com perda de pontos em pergunta não respondida.
- Acompanhar sequência (streak), pódio com medalhas e placar da semana ao vivo.
- Receber por e-mail / baixar o resumo de estudo com as respostas.

## Acesso
- Cada corretor entra com o próprio nome e um código de acesso pessoal.
- O gestor controla equipe, códigos e vídeo motivacional pelo "Modo gestor".

## Arquivo
- index.html — aplicação completa (HTML, CSS e JS em arquivo único; logo e medalhas embutidas).

## Publicação
Pode ser hospedado em qualquer lugar que sirva HTML estático (GitHub Pages, Netlify, etc.).
Para GitHub Pages: Settings > Pages > Branch: main > /(root).
